## 一、产品与设计母题

**拾鸟 WhatsBird** 是一款 Android 观鸟识别 App。打开即进取景页，对准鸟，端侧 AI 实时检测、
框住、当场报出中文名 + 学名 + 置信度，并按所在地区与季节重排候选。全程离线、不上传照片。

一句话定位：**「打开就是取景器的离线观鸟相机」+「把观鸟变成一本收集册」**——
专业自然观察工具，不是儿童/娱乐向产品。

设计母题 = **标本柜 × 拍立得 × 纸感图鉴**。观鸟记录天然是一种收集行为，界面应当像一本
摊开的自然图鉴：暖纸底上散落白框照片卡，等待被真实观测一格一格填满。

## 二、视觉语言：纸感收集册（Paper Almanac）

### 2.1 四条总纲

1. **纸，不是屏**：底色永远是暖纸米白（**永不纯白 `#FFF` 铺底**），层次靠白卡 + 柔影，
   不靠分割线。
2. **照片是主角**：一切 UI 色退为「装订线」（点缀、刻度、徽标），不跟鸟照抢色。
3. **分类学的庄重**：学名恒用衬线斜体（IUCN 徽标、区域徽章同属「图鉴语汇」）。
4. **收集要有仪式感**：完成度 %、空槽、加新标记——把「点亮」从状态变成仪式。

### 2.2 设计 token

| 维度 | 口径 | token（默认苔绿套） | 落 Compose |
|---|---|---|---|
| 底色 | 暖纸米白 | Paper `#F7F4EC` | 浏览页 `background/surface = Paper` |
| 主色 | 深苔绿（CTA/选中/进度） | Moss `#3A5540`（亮端 `#5A7A5F`） | `primary`；纸底对比 8.4:1 达 AA |
| 芯片 | 浅底 + 深字 | Sage `#E9F0E6` / Olive `#5B6B4F` | `PaperChip` 未选中态、分类学标签 |
| 点缀 | 暖琥珀（小面积：刻度条/时间戳） | Amber `#DDA45A` | 一色一义，禁止大面积使用 |
| 警示 | 铁红（new/稀有徽标专用） | Red `#E2483D` | `new` 胶囊；IUCN 红橙黄语义色固定不随主题 |
| 正文 | 近黑墨绿 | Ink `#1F2A22` | `onSurface` |
| 卡片 | 拍立得：白框厚下边、柔影、≤2° 微旋 | 圆角 16dp / 阴影 7dp | `shadow + rotate` |
| 排版 | 中文名粗体 → 学名衬线斜体 → 英文俗名 | Serif + Italic | zh=`titleBold` / sci=Serif Italic，全 app 品味锚点 |
| 未点亮 | 剪影/压暗图 + 「未点亮」胶囊 | Sil 渐变 `#EFEBDF→#E4DFCF` | 收集册里「等待填入的位置」 |
| 导航 | 悬浮胶囊，材质 = 卡面玻璃 + line 描边（随昼夜派生） | — | 全 app 一致 |

> ⚠️ v1–v3 的「取景页固定深色 + 种子色/动态取色」口径**已整体废止**。
> v4 起全 app（取景/图鉴/日志/设置/弹层）走单一纸感体系，昼/夜两态 + 五套配色。

**候选池淘汰记录**：青瓷（与默认套过近、区分度不足）、薄荷柠檬（否掉）。

### 2.4 昼夜派生

夜间模式三态：跟随系统 / 强制夜 / 关。夜间色板由 `PaperTokens.night()` 统一派生，
不手工维护第二套色值。**换主题/昼夜 = 14 色 token 逐色 250ms 交叉渐变**
（`PaperThemeState.animateForTheme()`），不做整体硬切。

### 2.5 一色一义（不破的规则）

| 色 | 语义 | 范围 |
|---|---|---|
| `primary`（纸感主色） | 品牌与主行动：CTA、选中态、进度条 | 全 app |
| 白系（反白 / white 14% / white 24%） | 选中与激活 | 取景页 HUD、导航胶囊、置信条 |
| 琥珀 `#DDA45A` | 时间与刻度，**小面积** | 时间戳、tick |
| 铁红 `#E2483D` | `new` 与稀有徽标 | 收集墙角标 |
| 检测框黄 `#FFD60A` | 仪表色：锁定目标 | **仅取景页**，不受主题 tint |
| 确认绿 `#30D158` | 仪表色：已记录 | **仅取景页**，不受主题 tint |
| 黑玻璃 | 场景层材质 | 取景页，不参与语义 |

**功能色让位主题色**：与内容无关的 accent（变焦指针、选中挡位、按钮）一律取
`MaterialTheme.colorScheme.primary`，不硬编码。相机功能色（检测框黄、确认绿）例外。

## 三、识别页（取景）

### 3.1 纸感罩框（方案 D）

画面圆角窗嵌在纸框里：顶栏 / 滚轮 / 结果面板全部坐在纸边上，检测框黄与对焦黑纱留在窗内。
HUD 变白后框与标签仍需自足对比——实测成立。

仪表层（对焦纱、检测框、框标签半透黑底）属「真实画面上的仪表层」，保留深色材质，
不受 UI 配色影响。

### 3.2 身份状态机

屏幕**只显示聚合身份，永不直接显示单帧结果**。

```
IDLE        无检测框                → 结果卡显示「找鸟中…」（弱色）
TRACKING    有框、身份为空或低置信   → 「识别中…」+ 充能条
IDENTIFIED  身份置信度达标           → 大字种类名 + 置信度条
LOST        框丢失 ≤5s（搜索窗内）   → 结果卡变暗、标注「沿用上次识别」，找回即恢复
（LOST 超窗 → 回 IDLE，身份清空 = 可能换了鸟）
```

**身份档案（TrackIdentity）**：字段 `(中文名, 学名, 最佳置信度, 置信累积, lastSeenAt)`。

- **只升不降**：新分类结果置信度 > 当前档案才更新，否则保留。差像素永远不覆盖好观测。
- **换鸟才重置**：仅当跟踪链断链超窗（memoryDet 清零）或重获取位置与预测位置连续性不符时
  清空；变焦、短暂丢失都不清空。

### 3.3 结果面板

```
┌──────────────────────────────────────┐
│  白鹮                                  │  ← 中文名 ≥22sp Bold
│  Nipponia nippon · 识别置信 87%        │  ← 拉丁名 12sp 次级色
│  ▓▓▓▓▓▓▓▓░░                           │  ← 置信度条
│  其他可能: 苍鹭 6% · 大白鹭 4%    [保存] │  ← 折叠的次候选
└──────────────────────────────────────┘
```

- 行序固化：中文名 → 学名 → 置信条 → 候选行/鸟已出画。**不得用 `Box` 叠放兄弟子项**
  （会互相覆盖），必须 `Column`。
- TRACKING 态：名称位置显示「识别中…」+ 充能条，**不给猜测值**（宁缺毋假）。
- 次候选默认折叠（防跳动感知），点开展开。
- **框上不放文字角标**——种类只在一个地方显示，即结果面板。
- 面板保留卡片形态（而非裸文字）：取景背景是持续运动的实拍画面，纯纱上放多行文字在亮场景会失读。
- 面板底部避让 76dp；底部导航胶囊高 56dp、外距 10dp。

### 3.4 聚合与滞回（实现参数）

| 参数 | 值 | 作用 |
|---|---|---|
| `EWM_HALF_LIFE_MS` | 1500 | 分类结果进指数加权窗，同种累加、异种竞争 |
| `EMIT_INTERVAL_MS` | 500 | 显示节流，防逐帧闪烁 |
| `HYSTERESIS` | 1.15 | 新第一名须超现第一名 1.15 倍才换位 |
| `CONFIDENT_PROB` | 0.35 | 身份置信达标门槛 |
| `MIN_IDENTIFY_HITS` | 3 | 连续一致帧数达标才定名 |
| `MIN_ROI` | 32 | 裁剪 ROI 最小边长；小于此值的图放弃重扫 |

- 分类触发：身份为空/低于门槛 → 分类；身份已高置信 → **停止分类**（省电 + 防闪烁），
  直到换鸟。
- 像素质量优先级：局部重检/中心扫描命中的**放大裁剪图**直接送分类器
  （1x 场景白捡等效 2x 的分类质量），优于全帧小框裁剪。
- ⚠️ **ROI 边界必须自洽**：`l` 的上界与 `roiW` 的上下界**必须用同一个 `MIN_ROI`**。
  2026-10-10 曾因 `roiW` 下界用 `MIN_ROI(32)`、`l` 上界用 `MIN_ROI/2(16)`，
  导致 `x + width > bitmap.width()` 抛 `IllegalArgumentException`（3 秒内 41 次，被 `catch` 吞掉、
  编译绿、Lint 0 error、肉眼无感）。**不要再引入「半边长」之类的派生常量。**

## 四、浏览页

### 4.1 图鉴

自上而下：`全国图鉴 标题 + 视图切换` → 白胶囊搜索 → **收集进度卡**（琥珀 tick + 完成度 % +
苔绿渐变进度条 + 「已点亮 N/384 · 本周加新 +n」带羽毛图标）→ 点亮态筛选胶囊（全部/已点亮/未见）→
区域筛选胶囊行（全部区域 + 六区，横滚）→ **双列拍立得收集墙**（微旋、`new` 红标、`×n` 次数角标、
区域徽章 + IUCN 胶囊、未点亮 = 渐变底鸟剪影 + 胶囊）。

点格进详情弹层：大图头（或剪影）→ 名/学名/IUCN → 分布归属 → 照片墙 → 我的观测（琥珀点时间线）→
（数据就位后加特征收集槽）。

**骨架 = 全国 384 种**（= 识别能力全集，无死格）。区域降级为**徽章/筛选器**：
每格显示该种归属哪几个区（数据源 = 六区 `guide_*.json` 联入，>2 区显示「前 2 + n」）。
进度 = 一个数 `N/384`；「已点亮」筛选即 life list 口径。IUCN 同源 guide json。

- 网格：`LazyVerticalGrid` Adaptive 116dp。
- 性能：图片解码沿用 `inSampleSize=4`；旋转用 draw 层 `graphicsLayer`，不触发重排。
- **已知行为（1 例）**：东北旧底册的百步 *Cuculus micropterus* 不在 384 里——东北模型若记到它，
  只进日志、不进图鉴、不计进度（无死格原则的代价）。

### 4.2 日志

按日分组的**列表流水**：`M月d日 EEEE · N 条` 日期头（sticky，滚动时钉在顶部）。
行点击开 `ModalBottomSheet` 详情：大图、时间/置信/区域/定位、Top-5 候选点选**改判**、
备注编辑保存、删除。顶部 MiniStat 走**纯流水口径**：记录数 / 近 7 日 / 人工确认。

删除 = 左滑跟手位移 + 越阈删除 + Snackbar 撤销（restore 整行回插，5s）。

### 4.3 设置

分组卡：外观 / 识别 / 数据 / 关于。**只放用户真的会来改的东西**。

- 外观：夜间模式三态 + 配色方案圆盘选择器（五套，点击弹出，即时生效并持久化）。
- 识别：检测器档位（自动 / 旗舰 / 中档）、区域模型、性能监控叠加层。
- 数据：导出 CSV（SAF）、清理缓存。
- 关于：版本、模型清单、开源许可、**支持拾鸟**、数据本地声明（支持拾鸟为 2026-10-11 加）。
  支持拾鸟是**全 App 唯一外链**，排在"数据位置"那行长说明**之前**（`ActionRow`，箭头自带"会跳走"的暗示）：
  点击跳爱发电主页，App 内**只放这一条裸链接**，不出现任何档位名/价格/回报——
  档位文案只活在爱发电页面上，口径见 `docs/legal/LICENSES.md` §H（免费 App + 纯自愿赞助安全区）。
  另：设置页滚动内容**底部留 96dp**（与日志/图鉴的 `contentPadding bottom` 同口径），
  否则最后一行会缩进底部那枚悬浮导航胶囊底下。

**页级大标题只在设置页有**（图鉴直接进进度卡、日志直接进汇总行），故顶部 sticky 发丝线
只上设置页；图鉴/日志若要加标题属于设计变更。

### 4.4 日志 / 图鉴的分工

两页**不合并**，回答的是两个不同问题：

| | 日志页 | 图鉴页 |
|---|---|---|
| 心智 | 「我**什么时候**见过什么」——流水 | 「这片地方有什么鸟、我还**差什么**」——收集 |
| 单位 | 一条观测记录 | 一个物种（× 区域底册） |
| 数据源 | `observations` 表本身 | `assets/guide/guide_<region>.json` 底册 × 记录 |
| 独有操作 | 详情 / 改判 / 备注 / 删除 | 点亮进度、未见筛选、物种详情弹层 |
| 形制 | 列表流水 | 收集册网格（方形图位 / 剪影格 / ×n 角标 / IUCN 徽标） |

图鉴详情弹层的脚注引流到日志页（「流水明细见日志页（搜索种名）」）。
未点亮格弹层 = 剪影知识卡 + 点亮引导。

## 五、动效

### 5.1 全局原则

1. **动效只服务三件事**：空间连续性（东西从哪来、到哪去）、状态确认（操作被听见了）、
   收集仪式（图鉴的灵魂）。纯装饰不排期。
2. **时长/曲线分档**：微交互 120–180ms（按压、勾选）；组件级 200–280ms（面板、chip）；
   页面级 320–420ms（全屏查看器、加新证书）。进场减速（decelerate/emphasized），
   退场加速（accelerate）；**弹跳只在「加新」一处允许**（仪式专属）。
3. **连续性优先**：从哪点开的，收回哪儿去。图鉴格 ↔ 详情弹层 ↔ 全屏查看是同一条空间链，
   不做「凭空 fade 出现」。
4. **降级与无障碍**：跟随系统「减弱动态效果」→ 全部转 150ms 纯淡入淡出，去位移/去落羽/去弹；
   色觉与对比不受动效影响。触觉分层：选择 `CLOCK_TICK` → 确认 `CONFIRM` → 加新 `SUCCESS` →
   删除撤销。

> ⚠️ **跨 Dialog 无法做真共享元素**：L2 详情弹层是 M3 `ModalBottomSheet`，
> 其内部本身就是包在 `Dialog` 里的，所以 L3 查看器实际是 **Dialog 套 Dialog**，跨不过合成边界——
> **升级 Compose 版本也解决不了**。全屏查看器用「开场 scale 0.92→1 + 下滑关闭」，
> **这是终稿**。

### 5.2 各屏动效

**识别页**

| 触发 | 动效 | 参数 |
|---|---|---|
| 进取景页 | 场景窗 scale-in + 预览首帧淡入（黑帧期用罩框纸底吸收，天然防闪烁） | 180ms decel |
| 检测框出现 | 四角括号内收锁定（先大 10% 收到位 + 透明度快速进），消失只淡出 | 150ms spring 高刚度 |
| 定名/换名 | 中文名 fade + 8dp 落定、置信条 `animateTo`、候选行内容驱动 | 220ms |
| 鸟出画 | 面板降透明 0.6，不消失 | tween 220 |
| 按记录 | 按钮 scale 0.96 按压 → 松手：快门白闪一帧 + 罩框轻微 zoom-punch + `CONFIRM` 振 + 勾号 scale-in「已记录」 | 白闪 80ms；脉冲 1.04 spring |
| 捏合/滚轮变焦 | 挡位药丸 ↔ 刻度盘交叉滑移 | 150ms |
| 识别中 | 球 600ms 上下 / 图标环 800ms 转圈（**故意不同频**，同频像心电图）+ 阴影第三节奏；候选名用等宽字体解码（100ms/字，随机 0~1000ms 揭示） | — |

**图鉴页**

| 触发 | 动效 | 参数 |
|---|---|---|
| 手指按住卡片 | 拍立得**归正 + 抬起**：rotate→0°、上浮 6px、阴影变深 | 140ms spring |
| 松手 | 共享展开：该照片放大飞至全屏查看器，背景暗纱渐入；关闭原路收回 | 320ms decel 进 / 220ms accel 回 |
| 未点亮卡点击 | **点亮仪式**：剪影淡出→照片淡入、卡片 pop（1→1.08→1）、×1 角标 scale-in、进度条同步注水、羽毛粒子落 3 片、`SUCCESS` 振 | pop 240ms spring；粒子 1.3–1.4s |
| 进页首屏 | 收集墙 stagger 依次浮现（fade + 上浮 48px + scale 0.9→1），仅首帧不重放 | 固定 25ms 步进、200ms 封顶、300ms 落位 |
| 筛选 chip 切换 | 网格重排 crossfade + move；chip 选中底弹簧 | 220ms |
| 进度卡 | 完成度 % 数字滚动 + 进度条从 0 注水 | 600ms decel |
| ×n 计数变化 | 角标数字弹一下（1→1.15→1） | 150ms |

> stagger 用**固定步进**，不用渐强延迟——渐强延迟是新手写法，第 30 项要等 900ms 才动，
> 用户会以为卡了。

**全屏查看器**

| 触发 | 动效 | 参数 |
|---|---|---|
| 打开 | 从缩略图共享展开（bounds 插值），无共享条件时 scale 0.92→1 + 纱渐入 | 300ms decel |
| 关闭/下滑 | drag-to-dismiss：跟手下移 + 缩放 + 透明度；**速度投影** `dy + vy/5 > 高度×0.5` 才关闭，否则弹回 | 物理跟手 |
| 多图 | 左右滑切换 + 连续量页码（随跨页轻微位移 + 淡出） | 跟手 |
| 缩放 | 双击 1x↔2.5x 定点放大；双指捏合**锚点落在手指位置** + 硬钳位 ≥1 | 250ms |

**日志 / 设置 / 导航**

- 日志：sticky 日期组头；行入场只 fade 不 stagger；删除 = 左滑 + **橡皮筋**（过冲 ÷10）+
  **速度判定**（`endTarget = vx + offset`，过 60% 才提交）+ 同时只允许一行打开 + Snackbar 撤销。
- 设置：配色/昼夜切换 = 全 app 250ms 交叉渐变；圆盘选中后 150ms 勾号放大再关层。
- 顶部 sticky 发丝线：滚过 **110px** 起步、**15px** 行程内淡入完毕的纸底 + 1px 发丝线。
- Tab 切换：内容 150ms crossfade（不做左右滑页）；导航胶囊内选中指示块共享移动
  （位置走 spring，宽度用带 40ms 延迟的 200ms tween——错拍 = 拉伸感）。
- 图鉴筛选行 chip：选中项插入 label 使 chip 物理变宽，兄弟间距收拢成一组。

### 5.3 曲线 / 弹簧对照表

换算关系：`stiffness = (2π/response)²`，`dampingRatio = dampingFraction`。

| 参照写法 | Compose | 用在哪 |
|---|---|---|
| `.snappy(duration: 0.25~0.3)` | `spring(dampingRatio = 0.8f, stiffness = 400f)` | 分段控件指示块、滑动删除提交/回弹 |
| `.smooth` / `.easeInOut(d)` | `tween(d*1000, easing = FastOutSlowInEasing)` | 绝大多数退场/淡入 |
| `.interactiveSpring(0.6, 0.7)` | `spring(0.7f, 109.7f)` | 粒子飞散、按钮归位 |
| `.interactiveSpring(0.4, 0.4)` | `spring(0.4f, 246.7f)` | 点亮仪式的 pop |
| `.interactiveSpring(0.8, 1.0~1.5)` | `spring(1f + i*0.15f, 61.7f)` | 逐位数字滚动（低位弹得更高） |
| `.bouncy` | `spring(dampingRatio = 0.7f, stiffness = 400f)` | 弹跳（只在点亮用） |
| `.repeatForever(autoreverses: true)` | `infiniteRepeatable(tween(d), RepeatMode.Reverse)` | 扫描线、找鸟中 |
| `.blendMode(.destinationOut)` | `BlendMode.Clear` | 圆形遮罩挖洞 |
| `.mask { content }` | `BlendMode.SrcIn` | 微光扫过 |

### 5.4 明确不做

视差滚动、卡片 3D 翻转、列表全量长 stagger、转场 overshoot 滥用（除加新外一律不弹）、
gooey/metaball 形变、Metal/AGSL 畸变、Glitch、逐字滤镜（Android 无对应 API）、
共享元素转场（已否决）——违背「标本柜的安静」气质，且低机位掉帧。

**例外**：全 app 需要「加载中」的视觉。模型首次下载、图鉴 384 条首次落库、照片首次解码成缩略图，
都是十几秒的空窗。做法是**「真组件喂假数据」**：`SpeciesCard(species: UiState)`，加载中喂
`Species.sample`，数据到了 `animate` 淡入替换——零重复布局、零骨架与真卡不一致的风险。
微光用**预烘焙 5 段 `Brush.horizontalGradient`** 靠 `graphicsLayer { translationX }` 推过去，
不用真模糊（`blurRadius = max(w/4, 30)` 在 Android 上太贵，视觉等价、GPU 成本差一个数量级）。

## 六、图标

### 6.1 图标语言

**全部图标 = 单色平涂剪影，Material 24dp 栅格，与底部导航图标同族。**

禁用 emoji、禁用描边线性风与剪影混用、禁用渐变/投影/拟物。
含描边细节时一律 round cap，描边宽度 ≥1.5dp 且全页统一。

### 6.2 定稿清单（12 枚）

| 图标 | 语义 | 造型要点 |
|---|---|---|
| 眼睛（filled/outlined 两态） | 导航·识别 | 杏仁外框 + 实心瞳 |
| 书签（两态） | 导航·日志 | 圆角矩形下缘 V 形切口的经典书签 |
| 图鉴册圈标 | 导航·图鉴 | 圆形徽记 |
| 齿轮 | 导航·设置 | Material 标准齿 |
| **歌鸟剪影** | 未点亮占位 / 品牌鸟 | 椭圆身 + 圆头 + 三角喙 + 上翘长尾 + 两条细腿（round cap 描边）；面朝右；24dp 内占 22dp，一眼是鸟不是鸡 |
| **羽毛** | 加新 / 收集进度 | 弧柳叶形羽片 + 一根斜羽轴（round cap 描边），约 45° 斜置 |
| 勾 | 人工确认 / 已记录 | 标准 M3 check |
| 铅笔 | 备注 | 45° 斜笔 + 短横基线 |
| 定位针 | 地址 / 分布 | 水滴针 + 中心圆孔 |
| 五角星 | 默认候选 | 实心标准星 |
| 放大镜 | 搜索 | 圆环 + 45° 斜柄 |
| 相机 | 特征收集空槽 | 机身 + 顶部取景凸台 + 同心镜头 |

新图标必须满足：**单色可 tint、24dp 缩到 16dp 不糊、负空间干净、圆角与笔画粗细与上表一致。**

已落地产物 = `res/drawable/ic_*.xml` **16 个文件**（12 枚清单含双态的折算 + 清单外的
`ic_moon` / `ic_palette`；`ic_note.xml` 即清单里的铅笔）。

### 6.3 启动图标

**银喉长尾山雀萌系形象 + 大问号**——口号 "WhatsBird?" 的直译：琥珀大问号当枝，
白色糯米团子鸟栖在其上。

萌化画法 = 头身一体的纯白圆球、小黑豆眼、极小三角喙、黑白细长尾羽；
**不画写实鸟、不做儿童卡通脸**。自适应启动图标输出五档密度（hdpi..xxxhdpi）。

### 6.4 生图硬规格

- 输出**满幅正方形**：不画圆角底板、不画手机壳/桌面 mockup、不加投影。
- **构图安全区**：凡「不能被裁掉」的主体元素，全部收进以画面中心为圆心、
  **直径 = 画面宽 62%** 的中央圆内（自适应图标画布 108dp、圆形遮罩可见区只有 66dp；
  iOS 圆角方还会额外吃掉四角）。圆外允许被裁且不心疼。
- 高对比、大负空间；最小笔画/最小特征 ≥ 画面宽度 4%；**缩到 48px 仍能一眼认出主体**。
  鸟腿、枝梢、羽毛丝一类 hairline 在 48px 必然消失——要么省略，要么加粗到 4% 以上。
- 浅色主体必须有对比兜底：纯白鸟形落在浅色底上时，底色加深一档，或给鸟加一圈极淡暖灰投影。
- 背景用纯色/极微弱光晕，**不要纸质噪点与纹理**（会糊掉缩略图边缘）。
- 扁平矢量风；主体单色或双色平涂，不画写实羽毛、不做金属反光与复杂渐变。
- 除 `?` 符号外，画面不得出现任何文字、字母、数字。
- 主色不超过 3 种（背景 + 主体 + 一个强调点）；默认用苔绿 `#3A5540`。
- **整套图标同族交付**：栅格、圆角、笔画粗细、朝向（鸟形统一面朝右）必须一致。

### 6.5 可用意象库（按贴合度）

1. **对焦框里的鸟** —— 核心体验「对准即识别」的直译；琥珀黄角括号 + 豆绿鸟形。
2. **眼睛 + 鸟** —— 导航「识别」即眼睛图标；观鸟圈行话「看到某鸟 = 一只 eye」。
3. **镜头光圈里的鸟影** —— 相机 + 观鸟的复合隐喻。
4. **收集册 / 一格一鸟** —— 纸感层母题：白卡网格 + 点亮格 vs 剪影格。
5. **羽毛** —— 收集仪式的记号（加新、进度、收藏册书脊）。
6. **书签 / 册页** —— 记录的次级功能。

自然元素（枝叶、羽毛、山脊线）可做点缀，但不要让画面变成「风景插画」；
鸟形一律用 6.2 的歌鸟剪影语言，不画写实鸟。
