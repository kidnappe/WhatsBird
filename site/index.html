这一版有什么

拍照识别

相机实时帧分析 + 三段式推理（检测 → 框选裁剪 → 分类 Top-5），逐帧给出候选。

区域模型

全国兜底 + 华北 / 华东 / 华中 / 华南西南 / 东北 五套区域分类器，按 GPS 自动路由，也可手动指定。

地理先验重排

用 BirdNET geomodel 的时空分布先验对分类结果加权重排（score = P图像 × P先验α）。

非鸟拒识门

独立的拒识分类器挡住非鸟目标，抑制误检。

多鸟识别

IoU 跟踪 + 主目标点选，群鸟场景逐只标框。

观测记录

按日流水，可改判 / 加备注 / 删除；CSV 全量导出（SAF，不申请存储权限）。

图鉴点亮

384 种中国鸟的收集册，含性状档案与保护状态（IUCN + 国家重点保护）。

离线逆地理

内置行政区划边界，无网也能把经纬度解析到区县。

纸感设计

全 app 统一的 Paper Almanac 视觉体系，五套配色 + 夜间派生。

怎么装

  1. 手机浏览器打开本页，点上面的「下载 APK」。约 119 MB，建议连 Wi-Fi。
  2. 允许安装未知应用。 下载完浏览器会拦一下，点「允许」——授权只给浏览器或文件管理器，不是全系统。
  3. 装。系统安装器点「下一步 → 完成」，无 root、无其他权限申请。
  4. 打开。首次会要相机权限。模型权重全在包里，装完断网也能用。

电脑上下载再传到手机？把 APK 通过数据线 / 网盘传到手机，用文件管理器点开， 同样需要允许「安装未知应用」。已经装过 v1.0 的话直接装新包即可升级，观测记录与图鉴进度都会保留。

你的照片去哪儿了

  • 照片与观测记录只写本机（files/records/ + Room），没有上传接口。
  • 定位用于地理先验与记录坐标，可关闭；无定位时先验退化为月度均值。
  • 地址解析走内置离线区划，不走任何第三方地理服务。
  • 导出的 CSV 由你自己选保存位置，App 不申请存储权限。
